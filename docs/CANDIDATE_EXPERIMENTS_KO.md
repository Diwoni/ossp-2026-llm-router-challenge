# 대안 모델 비교와 최종 채택 근거

## 한 줄 결론

최종 구성은 **파인튜닝 E5 라우터 + Qwen 오프라인 교사를 모방한 22KB 학생 head +
등급별 비용 안전장치**다. 복잡한 트리·문제군별 전문가·비용 분위수 모델은 독립
실험에서 과적합 또는 예산 위험이 확인되어 런타임에 넣지 않았다. 모델 선택에는
여러 분할, 스트레스 검사와 보수적 비용 상한을 공통 기준으로 적용했다.

## 최종 라우팅 구조

```text
입력 프롬프트
  ├─ 파인튜닝 E5 → 비슷한 공개 문제의 세 모델 성적 추정
  ├─ 짧은 길이·수식·코드 등 20개 내용 특징
  └─ Qwen 교사를 모방한 작은 학생 → E5가 놓친 의미 차이 보정
          ↓
세 모델(ax31-light / ax31 / axk1-think)의 예상 이득
          ↓
전체 배치에서 비용 제한을 넘지 않도록 모델 선택
          ↓
episode_id와 선택한 model_id만 JSON으로 출력
```

여기서 Qwen은 대회 평가 중 실행되지 않는다. 개발할 때 공개 프롬프트를 더 잘
이해하는 교사로 사용했고, 그 판단을 기존 E5 임베딩 160개와 내용 특징 20개만
보는 Ridge 학생에게 옮겼다. 최종 추가 계수는 22,894바이트다.

사용했으므로 숨은 평가 예상 점수가 아니다. 코드·자산 연결이 정확한지를 확인하는
검사 숫자다.

## Qwen 교사-학생 후보를 채택한 이유

고정한 Balanced 설정은 기존 E5 의미 점수에 학생 출력을 75% 섞고, 그 결과와
residual head를 50:50으로 합친다. 후보를 고른 뒤 서로 다른 방식으로 다시 나눈
7개 교차검증에서 모두 품질 변화가 양수였다.

| 분할 | seed | Balanced 변화 | 실제 비용비 |
| --- | ---: | ---: | ---: |
| 공식 공개 전체 3-fold | 20260825 | +0.002556818 | 1.740896 |
| 층화 5-fold | 20260825 | +0.000378788 | 1.756896 |
| 내용 군집 5-fold | 20260825 | +0.002272727 | 1.755514 |
| 층화 5-fold | 20260826 | +0.000189394 | 1.753868 |
| 내용 군집 5-fold | 20260826 | +0.002272727 | 1.769289 |
| 층화 5-fold | 20260827 | +0.001609848 | 1.750530 |
| 내용 군집 5-fold | 20260827 | +0.002840909 | 1.762576 |

Balanced 예산 한도는 2.0이므로 모든 분할에 약 0.23 이상의 여유가 있다. 원본
보고서는 [qwen-public-all-robustness.v1.json](../reports/qwen-public-all-robustness.v1.json)에
보존했으며 SHA-256은
`9dd1aa88a3d81ccb92acd22c5aae5fbdf34ae2c3d46db3ffdaec0dddd3be4a22`다.

7개 실험이 모두 같은 공개 2,640문항에서 파생됐다는 한계는 남는다. 따라서
`7/7 양수`는 숨은 점수 보장이 아니라, 현재 공개 자료 안에서 우연한 한 번의
Dev 상승보다 신뢰도가 높다는 뜻이다.

## 최종 등급별 설계

| 등급 | 최종 신호 | 안전 장치 |
| --- | --- | --- |
| Fast | 파인튜닝 E5 INT8 KNN | 안전계수 0.95, think 금지 |
| Balanced | E5 KNN → Qwen 학생 75% → residual과 50:50 | 안전계수 0.90 |
| Premium | hash 80% + 80토큰 동결 E5 20% | 안전계수 0.78 |

80토큰 동결 E5는 품질만 본 선택이 아니다. 128토큰 모델은 공식과 같은 ARM64
2CPU·2GiB·90초 조건에서 Fast/Premium이 시간 초과하여 제거했다. 최종 구조는
이후 깨끗한 커밋에서 Docker 이미지를 다시 빌드해 시간·결정성·역순 입력을
재검증한다.

## 독립 재현 결과

`scripts/evaluate_qwen_student.sh`로 현재 코드와 고정 자산을 새 출력 파일에 다시
실행했다.

| 등급 | 품질 | 비용비 | 예산 통과 |
| --- | ---: | ---: | :---: |
| Fast | 0.703977272727 | 1.195898885706 | 예 |
| Balanced | 0.701988636364 | 1.853913075828 | 예 |
| Premium | 0.747443181818 | 3.467426716815 | 예 |
| 가중 합계 | **0.716420454545** | - | 예 |

이 수치는 공개 전체 자산의 Dev 재대입 검사다. Premium 안전계수 0.84의 연구
후보는 0.717613636364였지만 문제군·비용 오차 스트레스 228개 중 4개를 실패해
최종 후보에서 제외했다. 최종 0.716420454545는 안전계수 0.78로 228개를 모두
통과한 값이다. 최종 채택 판단에는 재대입 최대 숫자보다 여러 분할의 방향 일치,
비용 여유와 공식 컨테이너 검사 결과를 우선했다.

## 최종 확인 항목

1. 현재 깨끗한 커밋에서 공식과 같은 ARM64 컨테이너를 새로 빌드한다.
2. 2CPU·2GiB·90초·네트워크 차단·읽기 전용 조건을 세 등급 모두 통과한다.
3. 입력 순서를 뒤집어도 episode별 선택이 같고 반복 실행 SHA가 같은지 확인한다.
4. 모든 최종 자산을 Release에 올리고 SHA-256 다운로드 검증을 자동화한다.
5. 공개 전체 자산 생성 과정과 라이선스·SBOM·실험 실패 기록을 제출 문서에 연결한다.
