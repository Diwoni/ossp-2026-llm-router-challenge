# 최종 실험 종합 보고서

## 결론

최종 제출 후보는 **파인튜닝 E5 + Qwen 교사-학생 보정 + 등급별 비용 배분기**다.
공개 Dev 재대입 최고치만 택하지 않고, 후보를 고정한 뒤 여러 분할·비용 변화·실행
환경에서 다시 확인했다. 그 결과 Premium의 공개 재대입 품질을 조금 포기하고
안전계수를 0.78로 낮춘 후보를 최종 채택했다.

우리가 자신 있게 말할 수 있는 것은 다음 네 가지다.

1. Train-only E5 기준선은 공식 hash-regex보다 공개 Dev에서 높았다.
2. Qwen 학생 보정은 공개 자료의 서로 다른 7개 교차검증에서 모두 양수였다.
3. 최종 비용 정책은 문제군과 비용을 흔든 228개 시나리오를 모두 통과했다.
4. 최종 이미지와 같은 rootfs는 공식형 ARM64 제한·반복·역순 검사를 통과했다.

숨은 평가 점수나 우승을 보장하는 숫자는 공개되어 있지 않다. 따라서 본 문서에서
공개 재대입 점수를 실제 심사 예측값으로 부르지 않는다.

## 실험 평가 원칙

### 쉬운 용어

- **홀드아웃**: 학습에 쓰지 않은 문제를 마지막에 한 번 풀어 보는 시험이다.
- **OOF**: 데이터를 여러 조각으로 나눠, 각 행을 그 행 없이 학습한 모델로 예측한
  값이다.
- **교차검증**: 조각을 바꿔 가며 여러 번 시험해 우연한 상승인지 확인한다.
- **재대입**: 학습에 쓴 문제를 다시 평가하는 검사다. 코드 연결 오류는 잘 찾지만
  새 문제 성능을 과대평가할 수 있다.
- **스트레스 검사**: 문제 비율이나 실제 비용을 일부러 바꿔 정책이 무너지지 않는지
  보는 시험이다.

후보는 품질 상승뿐 아니라 비용 통과, 최악 분할, 실행 시간, 라이선스를 모두
통과해야 채택했다. 한 분할에서만 오른 후보와 예산을 한 번이라도 넘긴 후보는
최종 런타임에서 제거했다.

## 기준선에서 최종 후보까지

| 단계 | 공개 Dev 또는 검증 결과 | 해석 | 판단 |
| --- | ---: | --- | --- |
| 공식 hash-regex | 0.695369318182 | 공식 공개 Dev 기준선 | 대조군 |
| Train-only E5 | 0.706846590909 | Train 학습 후 Dev 평가 | 기반 채택 |
| 공개 전체 E5 | 0.717329545455 | Train+Dev 학습 후 Dev 재대입 | 패키징 참고 |
| Qwen 학생 최종 | 0.716420454545 | 공개 전체 자산의 Dev 재대입 | 최종 회귀 검사 |

Train-only E5와 hash-regex의 차이는 +0.011477272727이다. 그러나 E5와 Qwen
최종 후보를 0.00957 상승으로 단순 비교하면 안 된다. Qwen 최종 자산은 Dev
outcome도 학습에 사용했기 때문이다.

## Qwen 학생을 채택한 근거

고정한 Balanced 후보는 E5 의미 KNN에 Qwen 학생 출력을 75% 섞고, 그 결과와
잔차 신호를 50:50으로 합친다. 같은 설정을 바꾸지 않고 다음 7개 분할에서
검증했다.

| 분할 | seed | Balanced 품질 변화 | 실제 비용비 |
| --- | ---: | ---: | ---: |
| 공식 공개 전체 3-fold | 20260825 | +0.002556818 | 1.740896 |
| 층화 5-fold | 20260825 | +0.000378788 | 1.756896 |
| 내용 군집 5-fold | 20260825 | +0.002272727 | 1.755514 |
| 층화 5-fold | 20260826 | +0.000189394 | 1.753868 |
| 내용 군집 5-fold | 20260826 | +0.002272727 | 1.769289 |
| 층화 5-fold | 20260827 | +0.001609848 | 1.750530 |
| 내용 군집 5-fold | 20260827 | +0.002840909 | 1.762576 |

7개 모두 방향이 양수이고 Balanced 제한 2.0보다 비용비가 0.23 이상 낮았다.
이 결과도 같은 공개 2,640문항에서 파생됐다는 한계가 있으므로 “숨은 평가에서
반드시 오른다”가 아니라 “한 번의 Dev 상승보다 재현성이 높다”로 해석한다.

원본: [`qwen-public-all-robustness.v1.json`](../reports/qwen-public-all-robustness.v1.json)

## 추가 모델을 버린 실험

외부 공개 학습 자료는 최종 실험에서 사용하지 않았다. 경쟁 포크에서 효과가
보고된 아이디어는 현재 코드와 공개 자료에서 독립적으로 다시 만들었다.

| 후보 | 선택 전 결과 | 고정 후 결과 | 최종 판단 |
| --- | --- | --- | --- |
| 생성 횟수 인지 GLM | OOF 종합 +0.003622 | Dev 종합 -0.002869 | 기각 |
| Fast 전문가 | 선택 seed 평균 +0.001619 | 고정 가중치 5 seed 중 양수 2개 | 기각 |
| Premium 비선형 GBM | OOF +0.006818 | Dev -0.011080 | 기각 |
| 문제군 Premium 전문가 | OOF +0.011790 | Dev -0.003693, 비용 4.099 | 기각 |
| 문제군별 강제 상한 | 고정선택 실패 28→2 | Premium 품질 -0.043845 | 기각 |

생성 횟수 인지 GLM·GBM을 모두 섞으면 Train OOF 종합은 0.6765909091에서
0.6802130682로 올랐지만, 후보 고정 후 Dev는 0.7006534091에서
0.6977840909로 내려갔다. “AI는 추가할수록 좋다”는 가정을 버리고, 일반화가
확인되지 않은 복잡성은 최종 경로에서 제거했다.

## 비용 안전계수 선택

총 228개 시나리오는 19개 문제군 비율과 4개 비용 상황을 세 등급에 적용한
결과다. 모델별 실제 비용은 변하지만 라우터의 비용 예측은 그대로 두어, 평가
분포를 미리 안다는 비현실적인 가정을 하지 않았다.

| Premium 안전계수 | 실패 | 공개 전체 Premium 품질 | 최악 비용비 | 판단 |
| ---: | ---: | ---: | ---: | --- |
| 0.84 | 4 | 0.761931818 | 4.219381 | 기각 |
| 0.80 | 2 | 0.757575758 | 4.057276 | 기각 |
| 0.79 | 1 | 0.756250000 | 4.013805 | 기각 |
| 0.785 | 0 | 0.755871212 | 3.991572 | 여유 부족 |
| **0.78** | **0** | **0.755303030** | **3.973534** | **채택** |

0.785도 계산상 통과하지만 4.0과의 여유가 0.0084에 불과하다. 0.78로 낮출 때
최종 가중 품질 손실은 약 0.00017이지만 추가 비용 여유를 얻는다. Premium이
한 번 초과하면 0.3 가중치 전체가 사라지므로 기대값 관점에서도 보수안이 낫다.
